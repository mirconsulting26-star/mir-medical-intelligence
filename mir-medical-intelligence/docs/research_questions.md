# Key Research Questions

## 1. Physiological Anomaly Detection
- *RQ-1.1*: How effectively can unsupervised models (Isolation Forest, Autoencoders) detect subtle physiological deterioration using routine CBC and metabolic panels alone?
- *RQ-1.2*: Does longitudinal delta-tracking (changes over time) improve anomaly detection sensitivity compared to single static laboratory measurements?

## 2. Missingness-Aware Prediction
- *RQ-2.1*: Which missingness representation (masking, indicators, native tree splits vs imputation) provides superior calibration under non-random missingness (MNAR)?

## 3. Adaptive Test Selection
- *RQ-3.1*: Can Expected Value of Information (EVI) policies reliably select the most informative next laboratory test to reduce predictive uncertainty while minimizing unnecessary testing?

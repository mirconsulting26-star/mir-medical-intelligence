# Contributing Guidelines

Thank you for contributing to **MIR Medical Intelligence**.

## Code & Research Standards
1. **Python Format & Linting**: Code should adhere to `ruff` formatting and `mypy` type annotations.
2. **Branching Strategy**: Use feature branches (`feature/track-a-cbc-baseline`, `docs/update-protocol`) and submit PRs for code review.
3. **CRediT Tracking**: Any significant contribution to research code, data curation, or documentation must be updated in `CRediT.md`.
4. **Reproducibility**: Ensure all pipeline steps are runnable via `python pipelines/...` or `pytest tests/`.

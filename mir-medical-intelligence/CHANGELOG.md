# Changelog

All notable changes to the MIR Medical Intelligence research repository will be documented in this file.

## [2.2.0] - 2026-09-05
### Added
- Created initial repository architecture combining scientific governance (Doc 1) and Python ML research engineering (Doc 2).
- Established `AUTHORS.md`, `CRediT.md`, `RESEARCH_ORIGIN.md`, `RESEARCH_GOVERNANCE.md`, and `DATA_GOVERNANCE.md`.
- Scaffolded modular `src/mir_medical` package structure across 16 core clinical intelligence submodules.
- Created `pipelines/` execution scripts for data ingestion, harmonization, cohort creation, training, evaluation, and report generation.
- Scaffolded R companion directory `r_companion/` for biostatistical and survey-weighted NHANES modeling.
